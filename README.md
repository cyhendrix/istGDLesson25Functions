# Lesson 25: Functions

Original practice activities aligned to Code.org CS Discoveries Unit 03, Lesson 25. Curriculum source: Lesson Materials Unit 03 Interactive Animations and Games, 141-page classroom PDF. Curriculum license: CC BY-NC-SA 4.0.

## Activities
Identify: 6 term matches. Build: 3 drag-and-drop code-order tasks with diagrams and keyboard alternatives. Apply: 4 predictions. Debug: 4 corrections. Total: 17 points. Partial code tasks state required existing setup.

## Student workflow
Student Information is the only first-page activity. Questions, answer choices, word bank, and code tiles shuffle once per attempt. Students click Check to see feedback. A perfect first check completes the tab; otherwise one more check is allowed, then students continue regardless of score. Browser progress saves locally. Every tab has Reset Entire Lab, with confirmation; it erases only this lesson's saved attempt, not recorded spreadsheet grades. Completed attempts offer Back to Lab and Return to Results on Student Info.

## Publishing and grading
Settings → Pages → Deploy from a branch → main → / (root). Submission remains disabled until the combined grade-submission.gs has been deployed to the EXISTING Game Design Grade Submission web app. This script preserves previous lessons and adds all 19 included lessons. After deployment, enable SUBMISSION_READY in index.html. The app only confirms a grade after a matching server receipt. Keep rosters and student IDs out of this public repository.
